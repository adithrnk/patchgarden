🌱 PatchGarden

A beginner-friendly, open-source contribution discovery platform.

PatchGarden helps newcomers explore open-source projects, identify missing repository essentials, and find practical ways to contribute through coding, design, documentation, and community support.

✨ Features

* 🔍 GitHub Repository Checker — Enter a public GitHub repository to check its README, contribution guidelines, code of conduct, and license.
* 🌿 Contribution Ideas — Explore beginner-friendly tasks across design, coding, documentation, and community support.
* ✅ Beginner Checklist — Follow simple steps to prepare for your first open-source contribution.
* 📝 Guide Generator — Generate a Markdown contribution guide for your project.
* 📱 Responsive Design — Works on mobile phones, tablets, and desktops.
* 🆓 Free & Open Source — No advertisements or paid subscriptions built into the project.

🎯 Mission

Our mission is to make open-source development more welcoming and accessible to everyone, especially beginners who don’t know where to start.

🚀 Getting Started

Option 1: Use GitHub Pages

1. Fork or create a copy of this repository.
2. Open your repository’s Settings.
3. Select Pages under the Code and automation section.
4. Choose Deploy from a branch.
5. Select the main branch and /(root) folder.
6. Save and wait for GitHub Pages to publish your website.

Option 2: Run Locally

1. Clone this repository:

git clone https://github.com/YOUR-USERNAME/PatchGarden.git

2. Open the project folder.
3. Open index.html in your web browser.

Replace YOUR-USERNAME with your GitHub username and update the repository URL if you use a different repository name.

🔐 Privacy

PatchGarden checks public GitHub repository information. It does not require a GitHub login for its basic repository-checking functionality. Requests to GitHub are subject to GitHub’s API availability and rate limits.

Do not enter passwords, access tokens, or other secrets into the website.
